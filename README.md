# 最后一班巴士 Demo · v7 物品观察与因果链

在 Chrome 或 Edge 中打开 index.html，无需安装依赖。封面与人物比例沿用已确认版本。

## 操作

- 点击陈伯或林晚开始轮回，右键选择人物时间线。
- 单击物品或线索查看信息卡，阅读时时间悬停、不消耗灵力。Esc、关闭按钮或背景可关闭；键盘 Tab 聚焦、Enter/空格查看。
- 干预：先点暂停（灵力 -2），按住道具向右拖，保持到完成。单击不会计为干预。完成后重新播放，观察人物的后续反应。
- 物品描述随本轮状态变化；已经观察到的信息记入命运档案，跨本次运行内的轮回保留。

## 本版场景

20:50 病房可调查饭盒和包布；23:15 护士站可调查病历、工具袋、压住标签的交接夹和交接单；23:20 医院门口可调查伞架与伞袋架；23:40 自动汇入共同车厢。交互时段重叠，右键可切换。

## 因果

阻止人物上车只得到表面结局：工具袋会由林晚、陈伯或已安排的车站取件员继续代交。包好饭盒、收好湿伞只改变局部失衡。移开遮挡标签的交接夹，时间恢复后林晚会看清待检说明、核对交接单并通知车站，工具袋留院。旧件不被误装，末班车因现有雨刷故障停运，进入真结局。假结局不再奖励永久获救或复色。

## 检查

桌面 Edge 已验证免费查看、阅读冻结时间、单击/拖动区分、键盘关闭、标签前后状态、代交流转、七种物品结局组合和跨轮回观察记录。tests/items.cjs 与 tests/finale.cjs 导出接收现有 Playwright Browser 和试玩 URL 的回归函数，不影响游戏运行。
